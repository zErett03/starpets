# StarPets — план запуска продаж на ggsel

> Пошагово, по фазам. Двигайся сверху вниз, не пропуская Фазу 1 (безопасность) и Фазу 2 (предполётные проверки).
> Аварийный стоп на любом этапе: **`GET /pause-all-offers`** — снимает все офферы с продажи (доставку уже оплаченных заказов не трогает).

## Фаза 0. Код в проде

## Фаза 1. Безопасность (СДЕЛАТЬ ДО ОТКРЫТИЯ ПРОДАЖ)
Все боевые секреты засветились в переписке/хендоффе — проротировать:
- [ ] **ggsel:** сменить пароль аккаунта и `GGSEL_API_KEY` (в кабинете ggsel → перевыпустить ключ).
- [ ] **StarPets:** запросить у вендора новые `secret` / `shared_key` / `account_id` (по возможности).
- [ ] **`ADMIN_PASSWORD`** — новый.
- [ ] **`WEBHOOK_SHARED_SECRET`** — новый. ⚠️ он вшит в URL вебхуков всех карточек, поэтому порядок строгий:
      1) сменить переменную в Railway (Variables → **Promote → Shared**);
      2) дождаться redeploy;
      3) `GET /fix-webhooks` — перепропишет precheck/notification URL всем офферам с новым секретом;
      4) проверить на 1–2 карточках, что в ggsel обновились ссылки уведомлений/precheck.
- [ ] Закрыть/почистить тест-эндпоинты, которые светят ключи в ответе (`/test-trade-status`, `/test-friendship` возвращают `Api_Key`/`Signature`). Минимум — убрать из ответа секреты; лучше — удалить/закрыть паролем.

## Фаза 2. Предполётные проверки (готовность к деньгам)
- [ ] **Баланс StarPets API-токена** достаточный (хендофф советует ≥ $50). Проверить в `/system-status`. Баланс токена ≠ баланс сайта — пополняет админ StarPets.
- [ ] **Боты StarPets онлайн** — подтверждено боевыми тестами (#26/#28 доставлены). Если планируешь много продаж — уточни у вендора запас ботов.
- [ ] **Вывод денег с ggsel настроен** (в хендоффе USDT-вывод «не настроен») — настроить payout, иначе деньги зависнут на балансе ggsel.
- [ ] **Ценообразование прибыльно:** наценка `MARKUP=1.20` (20%) должна покрывать комиссию ggsel + себестоимость StarPets + FX. Проверить на 2–3 позициях, что маржа положительная.
- [ ] **Прибрать тестовое:**
      - тест-карточку `102500472` снять с продажи / удалить оффер: `DELETE FROM offers WHERE ggsel_offer_id = 102500472;`
      - тест-заказы (#27 в `needs_attention` и др.) — закрыть/пометить, чтобы не мешали в `/admin`.

## Фаза 3. Активация витрины (собственно старт)
> Рекомендация: **софт-лонч** — сначала небольшой батч, а не все 13k разом. Посмотреть на первые живые заказы, потом масштабировать.

- [ ] `GET /sync-prices` → дождаться `[SyncPrices] done`. Обновит цены и `starpets_qty`, запаузит позиции без стока.
- [ ] **Maintenance mode:** если в `sync_prices` включён блок, глушащий авто-активацию paused-офферов (по summary — включён), реши:
      - оставить ручную активацию (ниже), **или**
      - выключить maintenance mode в коде + redeploy, чтобы sync сам активировал позиции с `qty>0`.
- [ ] **Активировать офферы:**
      - софт-лонч: активировать ограниченный набор (например, вручную несколько ходовых позиций через кабинет/точечно), проверить первые продажи;
      - полный запуск: `POST /activate-all-offers` — выставит на продажу все офферы с `qty>0`.
- [ ] Проверить на витрине ggsel, что активные карточки: видны, имеют поле «Roblox Username», настроены Уведомления/Precheck (Кастомные, POST) и редирект на `/delivery`.

- [ ] По первым 3–5 заказам пройти операторский чек-лист (`notes/launch-test-checklist.md`).

- [ ] Ловить в логах: `no_roblox_username`, `no_items_available`, коды StarPets, `[cancel_trade] FAILED`.

## Аварийные рычаги
- **Стоп продаж:** `GET /pause-all-offers` — снять всё с витрины.
- **Проблема с доставкой конкретного заказа:** `/admin` → «Новый трейд» / «Новый логин» / 🗑 «Отменить».
- **Ручной перезапуск выдачи:** `GET /trigger-deliver?order_id=X`.
- **Сменить ник заказа:** `GET /fix-order-username?order_id=X&username=Y`.

## Решения, которые надо принять до старта
1. Софт-лонч (батч) vs полная активация всех офферов.
2. Ротация секретов сейчас (рекомендуется) — с обязательным `/fix-webhooks` после смены `WEBHOOK_SHARED_SECRET`.
3. Maintenance mode: ручная активация vs авто в `sync_prices`.
